# Як влаштована прошивка

[English](../en/architecture.md) · [Зміст документації](README.md)

## Звідки код

Прошивка **Clock Informer 2.7.1** для ESP32 (автор — [Semen_p](https://www.thingiverse.com/thing:3924947), ліцензія
CC BY-NC 4.0) поширюється як готові файли прошивки; вихідного коду автор не публікує (ні для ESP32, ні для інших
плат). Тож без автора прошивку не можна ні змінити, ні виправити в ній помилку — це головна причина цього проєкту. Код
цього репозиторію відтворено з машинного коду 2.7.1:

- функції декомпільовано (Ghidra) й переписано на C++ під те саме ядро Arduino-ESP32 1.0.4 і ті самі бібліотеки;
- усі 376 функцій автора порівняно з оригіналом за машинним кодом (виклики, глобальні змінні, рядки, константи):
  120 — без жодної змістовної різниці, решта відрізняються переважно тим, як компілятор розклав тимчасові рядки,
  шаблони ArduinoJson і вбудовані функції; ключові функції (циферблат, кнопка, збереження налаштувань, погода
  тощо) перевірено вручну за всіма гілками;
- шрифти — побайтно; функції бібліотек табло — 115 зі 126 побайтно; 10 ефектів табло автора — однакова поведінка
  в емуляторі Xtensa (2000 випадкових сценаріїв, кожен стовпчик табло після кожного кроку);
- відтворену копію перевірено на справжньому годиннику.

Тег **`reconstructed-2.7.1`** — ця копія з поведінкою оригіналу (з його помилками). Усе, що змінено далі, видно в
історії git від цього тегу: `git diff reconstructed-2.7.1 v1.0.0`.

### Як читати код

- `g_c34ba` — глобальна змінна оригіналу; число — її адреса в RAM (`0x3ffc34ba`). Значення пояснено в `g.h`.
- `// @4011bb90` перед функцією — адреса функції в оригінальній прошивці; `f_400e3500` — функція, якій ще не дано
  змістовної назви.
- `// Виправлено: …` — що було не так у 2.7.1 і що змінено; `(нове, не з оригіналу)` у шапці файла — новий модуль.
- `ghidra.h` — типи декомпілятора, щоб перенесений код зберігав ті самі перетворення типів, що й оригінал.
- Кожен файл починається з опису українською й рядка `// EN:` англійською.

## Ядро 1.0.4 і `--wrap`

Ядро Arduino-ESP32 1.0.4 лишено тим самим, що в оригіналі: на ньому відтворено поведінку автора. Кілька його
слабких місць підмінено на етапі компонування (`-Wl,--wrap=…` у `platformio.ini`), не змінюючи ядра:

| Функція | Навіщо |
|---|---|
| `WiFiGenericClass::hostByName` | DNS через потік lwIP з очікуванням результату |
| `lwip_connect` | блокуюче з'єднання не довше `NET_CONNECT_TIMEOUT_S` |
| `settimeofday` | лічильник встановлень часу SNTP: «час справді отримано» |
| `xt_unhandled_exception`, `panicHandler` | запис причини аварії в RTC-пам'ять |
| `log_printf` | повідомлення ядра — і в сетевий журнал |
| `lwip_socket`, `lwip_accept`, `lwip_close_r` | облік сокетів (`sockdiag.cpp`) |
| `lwip_close` | → `lwip_close_r`: у цьому ядрі лише вона звільняє місце сокета |

## Розділи флеш-пам'яті

Як у прошивці автора (`firmware/partitions_clock.csv`): `nvs` 0x9000 (20 КБ), `otadata` 0xE000 (8 КБ), `app0`
0x10000 і `app1` 0x1F0000 (по 1 920 КБ, оновлення по мережі пишуть у вільний), `spiffs` 0x3D0000 (192 КБ:
`config.json`, мовні пакети, історія датчиків, журнал подій). Тому перехід з прошивки автора зберігає налаштування.
