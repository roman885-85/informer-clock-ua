# Документація Informer Clock UA

[English](../en/README.md) · [Головна сторінка проєкту](../../README.md)

Informer Clock UA — незалежна прошивка для годинника-інформера на ESP32 і світлодіодних матрицях MAX7219, заснована на
прошивці Clock Informer 2.7.1 автора [Semen_p](https://www.thingiverse.com/thing:3924947).

| Документ | Про що |
|---|---|
| [Інструкція користувача](https://roman885-85.github.io/informer-clock-ua/manual/?lang=uk) | перший запуск, сторінки веб-інтерфейсу, яскравість, ніч, час, оновлення, кнопка |
| [Прошивка](flashing.md) | усі способи прошити годинник: з браузера, скриптом, Flash Download Tool, esptool, PlatformIO, по мережі |
| [Підключення](wiring.md) | схема, таблиця виводів, живлення, два поверхи матриць, датчики, звук, корпус |
| [Збирання з вихідного коду](building.md) | PlatformIO, веб-інтерфейс, випуск нової версії, імітатори й перевірки |
| [Як влаштована прошивка](architecture.md) | звідки код, карта модулів, усі виправлення й нові функції, незалежність від сервера автора |
| [Налагодження по Wi-Fi](wifi-debug.md) | журнал роботи по мережі, прошивка по Wi-Fi, журнал подій і аварії |
| [Якщо щось не так](troubleshooting.md) | типові проблеми й що робити, як повідомити про помилку |

Уся документація одним PDF (з обкладинкою й змістом) і кожна частина окремо — серед файлів
[випуску](https://github.com/roman885-85/informer-clock-ua/releases): `informer-clock-ua-<версія>-docs-uk.pdf`.

Попередній випуск 1.0.0 ще не перевірено на годиннику — про помилки пишіть у
[Issues](https://github.com/roman885-85/informer-clock-ua/issues).
