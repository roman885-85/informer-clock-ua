Flash the clock from your browser

No software to install: you only need Chrome, Edge or Opera on a computer (Windows, macOS, Linux) and a USB data cable.

Як прошити

  1. Під'єднайте годинник (плату ESP32) до комп'ютера USB-кабелем.
  2. Натисніть «Під'єднати й прошити» і виберіть порт: CP2102/CP210x, CH340 або USB Serial.
  3. На запитання «Erase device?»:
    • не ставте позначку (не стирати) — оновлення або перехід із прошивки автора Clock Informer: Wi-Fi і всі налаштування зберігаються;
    • поставте позначку (стерти) — чиста установка на новий годинник, налаштування скинуться.
  4. Натисніть Install і зачекайте 1–2 хвилини до «Installation complete». Годинник перезапуститься сам.
  5. Новий годинник: під'єднайтеся до Wi-Fi «Clock ESP» (без пароля) і відкрийте http://192.168.4.1 — далі майстер налаштування.
Не під'єднується? Під час «Connecting…» натисніть і тримайте кнопку BOOT на платі 2–3 секунди. Якщо порт не видно зовсім — встановіть драйвер CP210x або CH340 і перевірте, що кабель не «лише для заряджання».

Інші способи

  • Оновлення по мережі — у веб-інтерфейсі годинника: «Оновлення» → «Оновити» (коли на годиннику вже Informer Clock UA).
  • Скрипт для Windows (flash.bat), macOS і Linux (flash.sh) разом із файлами прошивки — архів informer-clock-ua-…-flash.zip на сторінці випусків.
  • Flash Download Tool від Espressif, PlatformIO — повна інструкція.

How to flash

  1. Connect the clock (ESP32 board) to the computer with a USB cable.
  2. Press “Connect and flash” and choose the port: CP2102/CP210x, CH340 or USB Serial.
  3. When asked “Erase device?”:
    • leave it unticked (no erase) — update, or switching from the original Clock Informer firmware: Wi-Fi and all settings are kept;
    • tick it (erase) — clean install on a new clock, settings are reset.
  4. Press Install and wait 1–2 minutes for “Installation complete”. The clock restarts by itself.
  5. New clock: join the Wi-Fi network “Clock ESP” (no password) and open http://192.168.4.1 — the setup wizard starts.
Cannot connect? While “Connecting…” is shown, press and hold the BOOT button on the board for 2–3 seconds. If no port appears at all, install the CP210x or CH340 driver and make sure the cable is not charge-only.

Other ways

  • Over-the-air update — in the clock's web interface: “Update” → “Update” (once Informer Clock UA is installed).
  • A script for Windows (flash.bat), macOS and Linux (flash.sh) together with the firmware files — the informer-clock-ua-…-flash.zip archive on the releases page.
  • Espressif Flash Download Tool, PlatformIO — full guide.
